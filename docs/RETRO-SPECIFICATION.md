# Retroactive Specification

Baby-X collects deterministic evidence and stores specification candidates. Full Quirt later performs higher-level interpretation and repair reasoning.

Every statement is one of:

- declared requirement;
- static fact;
- observed invariant;
- hypothesis;
- falsified hypothesis.

Observed behavior never silently becomes owner authority.

Provenance records source identity, analyzer, operation, timestamp, target, and supporting artifact references. Contradictory observations falsify hypotheses without rewriting history.

Initial evidence sources include source, types, schemas, tests, package manifests, systemd units, nspawn definitions, runtime shapes, process topology, packets, traces, jobs, checkpoints, and counterexamples.
